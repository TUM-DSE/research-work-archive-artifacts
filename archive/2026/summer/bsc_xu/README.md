# MARS Rocq Sources

This repository contains Rocq source files for MARS, including `mars.v` and four versioned `mars_core` files.

## Repository Contents

| File | Description |
| --- | --- |
| `mars.v` | MARS Verilog source file. |
| `mars_core_V1.v` | Verilog source file labeled as version 1 of `mars_core`. |
| `mars_core_V2.v` | Verilog source file labeled as version 2 of `mars_core`. |
| `mars_core_V3.v` | Verilog source file labeled as version 3 of `mars_core`. |
| `mars_core_V4.v` | Verilog source file labeled as version 4 of `mars_core`. |
