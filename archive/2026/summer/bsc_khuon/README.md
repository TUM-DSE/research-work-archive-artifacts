## File-Layout-Aware Caching for Cloud-Native Analytical Query Engines

This repository contains the modified [duck-read-cache-fs](https://github.com/dentiny/duck-read-cache-fs) code developed as part of the thesis "File-Layout-Aware Caching for Cloud-Native Analytical Query Engines".

To keep the repository size manageable, [DuckDB](https://github.com/duckdb/duckdb) is not included. Both `duck-read-cache-fs/duckdb` and `duck-read-cache-fs/duckdb-httpfs/duckdb` must be populated with the DuckDB source code. The implementation has been tested against DuckDB commit `08e34c447bae34eaee3723cac61f2878b6bdf787`.
