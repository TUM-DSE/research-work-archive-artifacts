# HIP-*-gem5

- HIP-U-gem5 contains CHAI benchmark suite that is suitable for the system with unified memory
- HIP-D-gem5 contains CHAI benchmark suite that is suitable for the dedicated memory. In order to obtain those, we have used AMD hipify-perl tool.
